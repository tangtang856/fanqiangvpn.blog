一、🛑 故障特征定级与现象自查清单

遇到突发网络故障时，切忌病急乱投医盲目改动配置。首先对照以下清单快速定位故障源头：

  • 等级 A（全部超时）：客户端内所有节点测速均显示超时或 -1ms，无论是浏览器还是终端完全无法翻墙。
  • 等级 B（部分网站打不开）：Google、YouTube 可以正常访问，但 ChatGPT 提示 Access Denied 或特定外服游戏连不上。
  • 等级 C（关掉代理后电脑断网）：关闭客户端后，甚至连国内百度、微信都无法联网。

二、⚡ 黄金5分钟快速自愈流程 (按顺序执行)

面对突发断连，请严格按照以下标准化顺序排查：

  1. 第 1 分钟：检查本地系统时间。现代加密协议严格依赖时间戳同步，系统时间误差超过 90 秒会导致握手全部失败。右键任务栏时钟点击“立即同步”。
  2. 第 2 分钟：手动更新节点订阅。机场运维团队通常会在上游节点受阻后 5-10 分钟内部署全新备用入口，点击客户端“更新订阅”以拉取最新线路。
  3. 第 3 分钟：切换备用协议节点。若默认的 SS 节点受限，立即切换到该机场提供的 Hysteria 2、TUIC 或 Vless Reality 备用通道。
  4. 第 4 分钟：重置系统网络代理开关。进入 Windows“设置 -> 网络和 Internet -> 代理”，确保手动代理开关状态正常无残留锁定。

三、🛠️ 深度修复：命令行一键清理网络残留

若因软件非正常关闭导致电脑彻底无法上网，以管理员身份打开 CMD 或 PowerShell，逐行运行以下修复命令：

# 1. 强制清空本地 DNS 污染缓存
ipconfig /flushdns

# 2. 重置系统 Winsock 网络通信协议栈
netsh winsock reset

# 3. 重置系统 IP 路由转发参数
netsh int ip reset

执行完毕后重启电脑，网络即可彻底恢复初始健康状态。

四、🎒 极端时期的逃生备用网络军火库

成熟用户绝不会把所有鸡蛋放在同一个篮子里。我们强烈建议手头常备：

  • 备选冗余机场：推荐常备一个像飞V这样的低门槛按量不限时套餐，平日里不花月租，关键时刻作为应急救生艇随时顶上。
  • 小众冷门地区节点：在香港、日本等热门地区大堵车时，主动切换至英国、德国或台湾节点，往往能有出其不意的极速体验。

五、🔒 根治预防：构建永不断连的高可用环境

在日常配置中，可利用 Clash 的 fallback 策略组机制，将两家不同机场的专线节点聚合进同一选择器中。客户端会自动以固定间隔检测连通性，当主节点出现故障瞬间，系统将在零点几秒内无感切换至备用节点，真正实现 365 天永不掉线的极致体验。
