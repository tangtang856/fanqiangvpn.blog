Clash Verge Rev Windows 图文配置全教程 (Mihomo内核与TUN模式)

发布日期：2026-03-20 阅读预计：8 分钟 难度等级：入门到精通
📖 教程核心摘要：

Clash Verge Rev 是当前 Windows 平台最受欢迎的开源代理客户端。本教程手把手教你如何下载安装、导入机场订阅、开启系统代理并配置 TUN 虚拟网卡接管全系统流量。

一、Clash Verge Rev 客户端简介与下载

由于原版 Clash for Windows 已停止维护，基于开源 Mihomo (Clash.Meta) 内核开发的 Clash Verge Rev 已成为目前 Windows 上最稳定、界面最现代化且功能最强大的代理工具。它完全支持最新的 Hysteria 2、TUIC、Vless Reality 等前沿翻墙协议。

建议始终从官方 GitHub Release 页面下载以 .msi 或 .exe 结尾的最新 64 位安装包。首次安装完成后建议在“设置”中将语言切换为简体中文。

二、获取并导入机场订阅链接

登录你所购买的优质机场后台（如本站实测推荐的微风网络、暮光网络或隐形人专线），找到“一键导入”或“复制订阅链接”。

  1. 打开 Clash Verge Rev，点击左侧菜单栏的 “订阅” (Profiles)。
  2. 在顶部输入框中粘贴你的机场专属订阅链接。
  3. 点击 “导入” (Import)，客户端会自动下载远程节点列表并在本地保存配置。
  4. 右键该订阅卡片，可设置定时自动更新周期（建议设置为 24 小时自动更新）。
新手提示：若一键导入失败，可复制订阅链接后选择手动添加，或使用订阅转换工具转换为 Clash 格式。

三、选择分流策略组与节点选择

点击左侧的 “代理” (Proxy) 标签页，你会看到机场提供的节点分类：

  • 节点选择 (PROXY / Auto)：通常建议手动选择稳定性最高、延迟最低的专线节点（如香港 IEPL 01、日本 IPLC 01），或者选择“自动选择/负载均衡”。
  • 规则模式 (Rule)：请务必将出站模式设置为 “规则 (Rule)” 模式，国内网站（如百度、淘宝）将直连不消耗流量，外网网站（如 Google、YouTube、GitHub）则自动走代理。

四、开启系统代理与 TUN 虚拟网卡模式

在左侧 “设置” (Settings) 中，开启 “系统代理” (System Proxy) 开关，此时浏览器即可正常访问海外网络。

如果你需要给无法设置代理的软件翻墙（如部分外服网游、Epic Games、Steam 下载、WSL2 或命令行 Git），请在设置中开启 “TUN 模式”。TUN 模式会创建虚拟网卡接管系统底层所有 TCP/UDP 流量，实现真正的全局翻墙。

权限要求：开启 TUN 模式需要 Windows 管理员权限，首次开启请允许安装虚拟网卡服务。

常见问题解答 (FAQ)

❓ 为什么导入订阅后网页依然打不开？

请检查是否开启了系统代理开关，并在“代理”界面点击节点进行连通性延迟测试，确保选中的节点有有效毫秒数值。

❓ Clash Verge Rev 提示 Service Mode 未安装？

TUN 模式依赖核心服务，点击设置界面中“服务模式 (Service Mode)”旁边的“安装”，重启软件后即可正常开启。
