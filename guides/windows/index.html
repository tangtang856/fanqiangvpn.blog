Windows系统Clash Verge与节点配置指南

适用系统：Windows 10 / 11 (64位) 推荐客户端：Clash Verge Rev (基于Mihomo内核)
工具建议： 鉴于原版Clash for Windows已停更，目前Windows平台最推荐使用开源且活跃维护的 Clash Verge Rev，界面现代、内置中文字体且原生支持TUN虚拟网卡模式。

第一步：获取并安装客户端

访问 Clash Verge Rev 的官方 GitHub Releases 页面下载安装包并安装。

第二步：复制并导入机场订阅链接

  1. 登录你所购买的机场后台（如 微风网络 或 隐形人 控制台）。
  2. 在用户仪表盘找到“一键导入订阅”或“复制Clash订阅链接”。
  3. 打开 Clash Verge Rev，点击左侧菜单栏的 “订阅 (Profiles)”。
  4. 在顶部的输入框中粘贴刚才复制的订阅 URL，点击右侧的 “导入 (Import)”。

第三步：选择节点并开启系统代理

  1. 点击左侧 “代理 (Proxies)” 页面，选择 “规则 (Rule)” 模式。
  2. 选择低延迟节点后，在“设置”中开启 “系统代理” 开关。
