一、DMG 安装与安全性设置

从 GitHub 下载对应架构的 DMG 文件（M 系列芯片下载 aarch64.dmg，Intel 芯片下载 x64.dmg）。拖拽到 Applications 完成安装。若提示“无法打开未知名开发者应用”，前往“系统设置 -> 隐私与安全性”点击“仍要打开”。
