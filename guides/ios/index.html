苹果iOS小火箭与圈叉节点订阅配置教程

适用系统：iOS 14.0 及以上 (iPhone / iPad) 核心客户端：Shadowrocket (小火箭)
重要提示： 中国大陆地区的 App Store 无法下载 Shadowrocket 或 Quantumult X。必须使用海外地区（如美区、日区、港区）的 Apple ID 登录 App Store 才能进行下载安装。

第一步：获取海外 Apple ID 并下载小火箭

你可以自行注册一个美区 Apple ID，或者直接使用部分机场（如 一点机场）年付套餐赠送的共享外区账号。打开 App Store，点击右上角头像退出当前账号，登录海外账号搜索 Shadowrocket 并下载（注意正版开发者为 Pan modal，图标为一个黑色小火箭）。下载完成后建议立刻换回自己的国区账号。

第二步：添加机场订阅

  1. 在 Safari 浏览器中登录你的机场后台。
  2. 通常会有专门的 “一键导入 Shadowrocket” 按钮，点击后系统会自动唤醒小火箭并完成节点列表下载。
  3. 如果不支持一键唤醒，可复制订阅链接，打开 Shadowrocket，点击右上角 “+” 号。
  4. 类型选择 “Subscribe”，在 URL 一栏粘贴刚才复制的链接，点击右上角“完成”。

第三步：路由选择与启动

  1. 在小火箭首页下方，确保 “全局路由” 设置为 “配置 (Config)”（千万不要设为代理，否则国内流量也会耗费机场配额）。
  2. 在节点列表中轻点选中一个低延迟节点（前面出现黄色圆点即为选中）。
  3. 拨动顶部的连接开关，首次使用时会弹出 iOS 系统提示“Shadowrocket 想要添加 VPN 配置”，点击“允许”并输入手机锁屏密码。
  4. 状态栏显示 VPN 图标后，即可畅快访问全球互联网。
