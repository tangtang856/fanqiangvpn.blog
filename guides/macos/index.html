macOS系统Clash与节点配置指南

适用系统：macOS 11+ (Intel 及 Apple M1/M2/M3/M4芯片) 核心客户端：Clash Verge Rev for Mac

macOS平台过去流行的ClashX已长期停止更新，目前针对Apple Silicon芯片优化的首选软件同样是 Clash Verge Rev (macOS DMG包)。

安装与安全权限授予

  1. 下载对应架构的 DMG 文件（M系列芯片请下载 aarch64.dmg，旧款Intel芯片请下载 x64.dmg）。
  2. 打开 DMG 并将 Clash Verge 拖入“应用程序 (Applications)”文件夹。
  3. 首次打开若提示“无法验证开发者”，请进入系统“设置” → “隐私与安全性” → 点击“仍要打开”。

开启 TUN 增强模式（接管全系统流量）

Mac 终端（Terminal）、Docker 或部分未遵循系统代理的环境默认不会走代理。通过开启 TUN 模式，可以在系统内核层创建一个虚拟网卡，彻底解决命令行无法 git clone 或下载外网资源的问题：

  1. 在 Clash Verge 设置中，授予软件服务安装权限（Service Mode）。
  2. 开启 “TUN 模式” 开关。
  3. 在终端执行 curl ipinfo.io，若返回境外 IP 则说明终端代理配置成功。
