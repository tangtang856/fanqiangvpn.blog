Android安卓平台机场节点客户端配置教程

适用系统：Android 8.0 及以上 推荐客户端：Clash Meta for Android (CMFA) / v2rayNG

一、客户端选择建议

安卓系统目前主流推荐两个客户端：

  • Clash Meta for Android (CMFA)： 支持分流规则与多协议内核，功能强大，适合绝大多数中重度用户。
  • v2rayNG： 单节点管理极其轻便，支持直接扫码导入单个V2Ray或Trojan节点。

二、CMFA 导入订阅步骤

  1. 在手机浏览器中打开机场官网，复制Clash订阅链接。
  2. 启动 Clash Meta for Android，点击 “配置 (Profiles)” → 点击右上角 “+” 号。
  3. 选择 “URL”，在“名称”栏随意填写（如五叶网络），在“URL”栏粘贴你的订阅链接。
  4. 点击右上角的保存图标，等待配置下载完成后，点击选中该配置。
  5. 返回主界面，点击中央的 “点击启动” 按钮，首次启动会弹出系统的 VPN 连接请求，点击“确定”。
  6. 在“代理”选项卡中选择你喜欢的节点，即可畅享跨境网络。

三、安卓系统后台防杀保活设置

国产安卓定制系统（MIUI/HyperOS、OriginOS、ColorOS等）后台管理激进，常常在锁屏后自动杀死代理进程。解决方法：

  • 在手机系统的“设置” → “应用管理”中找到 Clash，开启“自启动权限”。
  • 在电池优化策略中，将其设置为“无限制”或“不优化”。
  • 在多任务后台卡片界面，长按 Clash 卡片并点击加锁图标。
